Personalized Learning Path Generator
A React + Vite (TypeScript) MVP that creates custom learning roadmaps from mock course data, with progress tracking via localStorage and PDF export.
Features

Multi-step form to generate learning paths based on career goals.
Dashboard with course cards (Beginner, Intermediate, Advanced).
Track course progress in localStorage.
Export roadmaps as PDF.
Responsive UI with vanilla CSS.
Accessible with ARIA standards.

Tech Stack

React 18+, Vite, TypeScript
Zustand, React Router v6, React Hook Form, Axios
jsPDF, react-hot-toast

Setup

Clone: git clone <repo-url>
Install: cd pathgenerator && npm install
Run: npm run dev (open http://localhost:5173)
Build: npm run build

Deployment

Build: npm run build
Push to GitHub: git push origin main
Deploy to Vercel/Netlify: Import repo or upload dist/.
